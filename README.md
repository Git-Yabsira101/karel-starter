# Karel the Robot

This is my Karel project that I did for COSC 10001: The Computer Science Experience. 
I used Java and Karel to practice and learn basic programming concepts: including methods,loops,
movement, and picking up and placing beepers.

## How to Run It

After opening the `karel-starter` folder in IntelliJ, open `MyKarel.java`and click the Play or green Run button.

## What I Learned

1. How to combine Karel's basic commands to create different movements and actions.
2. How to use loops for repeated or repetitive actions.
3. How to create my own methods and use them.
